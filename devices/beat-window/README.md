# Alberton Beat Window

An audio effect that shows the beat in a floating window: the beat number, large and warm
on a dark disc, the bar.beat position beneath it, and a ring that lights on every beat. The
window floats over Live, can be resized from any corner and the drawing follows its size. A
small copy of the drawing sits on the device itself, for when the window is closed.

Put it anywhere audio passes, the Main track for instance: it passes audio through
untouched and reads the position from Live's transport.

| Parameter | Default | What it does |
|---|---|---|
| `Float Window` | on | opens and closes the window (it opens by itself when the set loads) |
| `Flash` | on | whether the ring lights on the beat |
| `Blink` | 25 % | how long the ring stays on, as a share of the beat, so it follows tempo and signature and can never stay lit into the next beat |

The beat number is the beat within the bar, 1-based, as in Live's own display; in 12/8 a
beat is an eighth. If the window was closed with its own close box, switch `Float Window`
off and on to open it again.

Source: `beat-window.js`, an mgraphics `jsui` script, embedded in the `.amxd`. The patcher
is generated by `tools/build_devices.py`.
