# Alberton Kit FX Receiver

The audio-effect half of the Kit Selector: one per rack whose macros a kit should set. It
can sit on any kind of track, a group included, which is why it is an audio effect and not a
MIDI one. It governs **the nearest rack**: the rack it lives inside when it sits in a chain,
otherwise the first rack after it on the track, or failing that the last one before it.
Placement is the binding; no names.

| Parameter | What it does |
|---|---|
| `Bank` 1–9 | which fx bank of the panel this rack follows |
| `Bus` 1–4 | the panel's bus |
| `Apply Volume` | the bank's FX Volume sets this track's volume |
| `Applied` | how many macros the last recall wrote (a display) |

A recall writes the bank's nine values to macros 1–9 of the rack; a macro that is disabled
(hidden, or mapped elsewhere) is skipped quietly. **FX Capture** on the panel asks every fx
receiver for its rack's macros, which is how a sound found by hand becomes part of a kit.
Audio passes through untouched.

Source: `kit-fx-receiver.js`, embedded in the `.amxd`. The patcher is generated by
`tools/build_devices.py`.
