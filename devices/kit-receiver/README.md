# Alberton Kit Receiver

The MIDI-effect half of the Kit Selector: one per track that should follow a strip of the
panel. Put it before the instrument. It listens on the bus and acts on its own strip only.

| Parameter | What it does |
|---|---|
| `Strip` 1–16 | which strip of the panel this track follows |
| `Bus` 1–4 | the panel's bus |
| `Action` | what the strip's program means here (below) |
| `Apply Volume` | the strip's volume sets this track's volume |
| `Last` | the last program received (a display) |

**Action.** *Program Change* sends the program on as a MIDI program change to the instrument
after it. *Chain Selector* writes the chain selector of the rack. *Macro 1–16* writes that
macro of the rack. *None* ignores the program, for a track that only wants its volume from
the panel. The rack is the one the receiver sits inside when it is in a rack chain, otherwise
the first rack on the track. No track or device is known by name.

It introduces itself to the panel (`bound <strip> <track name>`) at load, when its strip
changes and when asked, so the panel labels its strips after the tracks. MIDI passes through;
only the program change is added.

Source: `kit-receiver.js`, embedded in the `.amxd`. The patcher is generated by
`tools/build_devices.py`.
